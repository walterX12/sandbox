## 💰 Cenové modely

### Běžné cenové modely Car Rental API (2026)

| Model | Popis | Vhodné pro |
|-------|-------|-----------|
| **Commission-based** | Provize za každou rezervaci | Většina projektů |
| **Partnership agreement** | Individuální smluvní podmínky | Střední-velké firmy |
| **Volume-based** | Slevy při vyšších objemech | Velké platformy |
| **Free partner programs** | Zdarma s provizním modelem | Startupy |
| **Monthly fee** | Fixní měsíční poplatek (vzácné) | Enterprise |

### Typické provize

- **Agregátoři:** 15% - 30% z hodnoty rezervace
- **Přímí poskytovatelé:** 10% - 20% z hodnoty rezervace
- **Volume deals:** 5% - 15% (při vysokých objemech)

**Poznámka:** Konkrétní ceny nejsou veřejně dostupné a závisí na:
- Objemu rezervací
- Geografickém pokrytí
- Délce partnerství
- Typu vozidel

### Technologie

| Poskytovatel | Protokol | Formáty | Rate limiting | Developer portal |
|-------------|----------|---------|---------------|------------------|
| Avis Budget | RESTful | JSON | Ne (2026) | ✅ developer.avis.com |

| Rentalcars | RESTful | JSON | Ano | ✅ Partner program |
| Booking.com | RESTful | JSON | Ano | ✅ (omezený přístup) |

### Základní workflow pro rezervaci

```
1. Location Search (vyhledání depotek/lokalit)
   ↓
2. Vehicle Search (dostupná vozidla)
   - Datum/čas vyzvednutí
   - Datum/čas vrácení
   - Lokace pickup/dropoff
   ↓
3. Vehicle Details (detaily vozidla)
   - Typ vozidla
   - Cena
   - Pojištění
   - Dodatečné služby
   ↓
4. Reservation Request (rezervace)
   - Informace o řidiči
   - Platební údaje
   ↓
5. Confirmation (potvrzení)
   - Reservation number
   - Pickup instrukce
   ↓
6. [Optional] Modification/Cancellation
```

### Klíčové funkce k ověření

- ✅ Real-time vehicle availability
- ✅ Dynamic pricing
- ✅ Multi-currency support
- ✅ One-way rentals (jiná lokace vrácení)
- ✅ Insurance options
- ✅ Additional services (GPS, child seats, atd.)
- ✅ Cancellation policies
- ✅ Modification support
- ✅ Vehicle filters (type, transmission, fuel)
- ✅ Depot/location search
- ✅ Driver requirements (věk, licence)

## ⚠️ Důležité poznámky

### Přístup k API
- **Většina poskytovatelů** vyžaduje **partnerskou dohodu**
- **Ceny nejsou veřejné** - nutný kontakt s sales týmem
- **Schvalovací proces** může trvat **týdny**
- **Rentalcars.com** nabízí **free partner program** - nejjednodušší start

### Technické požadavky
- Většina API vyžaduje **HTTPS** připojení
- Implementujte **error handling** (vozidlo již nedostupné, atd.)
- **Cachování** - ceny se rychle mění, ale struktura dat ne
- Ověřte **rate limits** u každého poskytovatele

### Business požadavky
- **Pojištění:** Ověřte, jaké typy pojištění API nabízí
- **Dodatečné poplatky:** Mladý řidič, další řidič, GPS, atd.
- **One-way rentals:** Ne všechna API podporují
- **Mezinárodní řidičský průkaz:** Ověřte požadavky

### Compliance
- **GDPR:** Pro evropské zákazníky
- **PCI DSS:** Pokud zpracováváte platby
- **Terms of Service:** Každý poskytovatel má vlastní pravidla
- **Branding:** Ověřte, zda můžete používat loga půjčoven

## 💡 Pro Madeiru (říjen 2026)

### Doporučení pro Madeiru:

**1. Nejvhodnější poskytovatelé:**
- **Europcar** - silná pozice na Madeiře, evropský standard
- **Sixt** - prémiové vozy, dobré pro ostrovní turistiku
- **Rentalcars.com** - agregátor s největším výběrem lokalit

**2. Co ověřit:**
- ✅ Pokrytí letiště Funchal (FNC)
- ✅ One-way možnosti (letiště → hotel → různé město)

- ✅ Automatická vs manuální převodovka
- ✅ GPS/navigace (užitečné na ostrově)

**3. Specifika Madeiry:**
- Ostrov s hornatým terénem → důležité pojištění
- Úzké silnice → menší vozy jsou praktičtější
- Letiště Funchal je hlavní pickup point
- V říjnu je turistická sezóna → rezervujte předem

**4. Integrační strategie:**
- **Začněte s:** Rentalcars.com (free partner program)
- **Přidejte:** Europcar API (pro přímé ceny)
- **Premium segment:** Sixt API (pro náročné zákazníky)
