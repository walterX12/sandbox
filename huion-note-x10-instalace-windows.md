# Huion Note X10 - Instalace aplikace pro Windows

## Přehled

Huion Note X10 je hybridní grafický tablet, který funguje jak samostatně (Android), tak připojený k PC. Pro práci s Windows potřebujete nainstalovat dva programy.

## Co budete potřebovat

1. **Huion ovladače** - pro rozpoznání tabletu
2. **Huion NoteLite** - aplikace pro zobrazení a správu vašich kreseb (ekvivalent Android aplikace)

## Krok 1: Stažení ovladačů

### Doporučená cesta - Oficiální web Huion

1. Otevřete prohlížeč a jděte na: **https://www.huion.com/download/**

2. V sekci "Driver" najděte:
   - **Product Type**: Pen Display / Pen Tablet
   - **Product Model**: Vyberte "Note X10"
   - **OS**: Windows

3. Stáhněte nejnovější verzi ovladače (Huion Driver)

### Alternativa - Přímý odkaz

Pokud máte problém najít ovladač, můžete vyhledat:
- "Huion Note X10 Windows driver download"
- Nebo navštivte: https://www.huion.com/support.html

## Krok 2: Instalace ovladačů

1. **Spusťte** stažený instalační soubor (obvykle `HuionTablet_WinDriver_vXX.X.X.XXX.exe`)

2. **Postupujte** podle průvodce instalací:
   - Klikněte "Next" / "Další"
   - Přijměte licenční podmínky
   - Nechte výchozí instalační cestu
   - Klikněte "Install" / "Instalovat"

3. **Restartujte** počítač po dokončení instalace

## Krok 3: Stažení aplikace Huion NoteLite

### Co je NoteLite?

NoteLite je aplikace pro Windows/Mac, která zobrazuje vaše kresby z Huion Note X10 - **toto je ekvivalent té aplikace, kterou máte v Androidu**.

### Jak stáhnout:

1. Jděte opět na: **https://www.huion.com/download/**

2. V sekci "Software" najděte:
   - **NoteLite** (nebo "Huion NoteLite for Windows")

3. Stáhněte nejnovější verzi

## Krok 4: Instalace NoteLite

1. **Spusťte** instalační soubor NoteLite

2. **Postupujte** podle průvodce:
   - Přijměte podmínky
   - Vyberte instalační složku
   - Dokončete instalaci

3. **Spusťte** aplikaci NoteLite z ikony na ploše nebo nabídky Start

## Krok 5: Připojení tabletu k PC

### Použití USB kabelu:

1. **Připojte** Huion Note X10 k PC pomocí USB-C kabelu

2. **Zapněte** tablet

3. Windows by měl automaticky rozpoznat zařízení

4. **Otevřete** aplikaci NoteLite - měli byste vidět obsah tabletu

### Možnosti připojení:

- **USB kabel** - doporučeno pro stabilní spojení
- **Bluetooth** - možné, ale může být pomalejší
- **WiFi** - některé modely to podporují

## Co NoteLite umožňuje:

✅ Zobrazení všech kreseb a poznámek z tabletu
✅ Export do PDF, JPG, PNG
✅ Synchronizace souborů mezi tabletem a PC
✅ Organizace do složek
✅ Živé zobrazení při kreslení

## Řešení problémů

### Tablet není rozpoznán:

1. Zkontrolujte, zda jsou **ovladače správně nainstalované**
2. Zkuste **jiný USB port** (preferujte USB 3.0)
3. Zkuste **jiný USB kabel**
4. **Restartujte** PC i tablet

### Pero nefunguje:

1. Otevřete **Huion Tablet Driver** (aplikace nainstalovaná s ovladači)
2. Zkontrolujte, zda je tablet viditelný
3. Zkalibrujte pero v nastavení ovladače

### NoteLite neukazuje kresby:

1. Ujistěte se, že je tablet **připojený a zapnutý**
2. V NoteLite klikněte na **Refresh / Obnovit**
3. Zkontrolujte, zda máte na tabletu nějaké uložené soubory

## Alternativní software

Kromě NoteLite můžete používat i další aplikace:

- **Huion Sketch** - kreativní kreslení
- Standardní kreslící software jako **Adobe Photoshop**, **Krita**, **GIMP** - fungují s tabletem jako vstupní zařízení

## Důležité poznámky

⚠️ **Vždy instalujte ovladače PŘED prvním připojením tabletu**
⚠️ **Pravidelně aktualizujte ovladače** - Huion vydává aktualizace s opravami
⚠️ **NoteLite je zdarma** - neplaťte za podezřelé verze z neoficiálních zdrojů

## Shrnutí instalace:

1. Stáhněte **Huion Driver** z huion.com
2. Nainstalujte ovladače a restartujte PC
3. Stáhněte **Huion NoteLite** z huion.com
4. Nainstalujte NoteLite
5. Připojte tablet USB kabelem
6. Spusťte NoteLite a užívejte si malování! 🎨
