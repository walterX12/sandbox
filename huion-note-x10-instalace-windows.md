# Huion Note X10 - Instalace aplikace pro Windows

## Přehled

Huion Note X10 je hybridní grafický tablet, který funguje jak samostatně (Android), tak připojený k PC. Pro práci s Windows potřebujete nainstalovat dva programy.

> **⚠️ Upozornění k názvům:** Aplikace se může jmenovat **"Huion Note"** nebo **"Huion Note for PC"** (ne "NoteLite", jak jsem původně uvedl). V tomto návodu používám obecný název - hledejte "Huion Note" aplikaci pro váš systém.

## Co budete potřebovat

1. **Huion ovladače** - pro rozpoznání tabletu jako kreslícího zařízení
2. **Huion Note aplikace** - aplikace pro zobrazení a správu vašich kreseb (ekvivalent té Android aplikace, kde vidíte pěkně malování)

## Krok 1: Stažení ovladačů

### Doporučená cesta - Oficiální web Huion

1. Otevřete prohlížeč a jděte na: **https://www.huion.com/download/**

2. V sekci "Driver" najděte:
   - **Product Type**: Pen Display / Pen Tablet
   - **Product Model**: Vyberte "Note X10"
   - **OS**: Windows

3. Stáhněte nejnovější verzi ovladače (Huion Driver)

### Alternativa - Přímý odkaz

Pokud máte problém najít ovladač, můžete vyhledat:
- "Huion Note X10 Windows driver download"
- Nebo navštivte: https://www.huion.com/support.html

## Krok 2: Instalace ovladačů

1. **Spusťte** stažený instalační soubor (obvykle `HuionTablet_WinDriver_vXX.X.X.XXX.exe`)

2. **Postupujte** podle průvodce instalací:
   - Klikněte "Next" / "Další"
   - Přijměte licenční podmínky
   - Nechte výchozí instalační cestu
   - Klikněte "Install" / "Instalovat"

3. **Restartujte** počítač po dokončení instalace

## Krok 3: Stažení aplikace Huion Note

### Co je Huion Note?

Huion Note je aplikace pro Windows/Mac, která zobrazuje vaše kresby z Huion Note X10 - **toto je ekvivalent té aplikace, kterou máte v Androidu**.

### Jak stáhnout:

1. Jděte opět na: **https://www.huion.com/download/**

2. V sekci "Software" najděte:
   - **Huion Note** (nebo "Huion Note for Windows")

3. Stáhněte nejnovější verzi

## Krok 4: Instalace Huion Note

1. **Spusťte** instalační soubor Huion Note

2. **Postupujte** podle průvodce:
   - Přijměte podmínky
   - Vyberte instalační složku
   - Dokončete instalaci

3. **Spusťte** aplikaci Huion Note z ikony na ploše nebo nabídky Start

## Krok 5: Připojení tabletu k PC

### Použití USB kabelu:

1. **Připojte** Huion Note X10 k PC pomocí USB-C kabelu

2. **Zapněte** tablet

3. Windows by měl automaticky rozpoznat zařízení

4. **Otevřete** aplikaci Huion Note - měli byste vidět obsah tabletu

### Možnosti připojení:

- **USB kabel** - doporučeno pro stabilní spojení
- **Bluetooth** - možné, ale může být pomalejší
- **WiFi** - některé modely to podporují

## Co Huion Note umožňuje:

✅ Zobrazení všech kreseb a poznámek z tabletu
✅ Export do PDF, JPG, PNG
✅ Synchronizace souborů mezi tabletem a PC
✅ Organizace do složek
✅ Živé zobrazení při kreslení

## Řešení problémů

### Tablet není rozpoznán:

1. Zkontrolujte, zda jsou **ovladače správně nainstalované**
2. Zkuste **jiný USB port** (preferujte USB 3.0)
3. Zkuste **jiný USB kabel**
4. **Restartujte** PC i tablet

### Pero nefunguje:

1. Otevřete **Huion Tablet Driver** (aplikace nainstalovaná s ovladači)
2. Zkontrolujte, zda je tablet viditelný
3. Zkalibrujte pero v nastavení ovladače

### Huion Note neukazuje kresby:

1. Ujistěte se, že je tablet **připojený a zapnutý**
2. V Huion Note klikněte na **Refresh / Obnovit**
3. Zkontrolujte, zda máte na tabletu nějaké uložené soubory

## Alternativní software

Kromě Huion Note můžete používat i další aplikace:

- **Huion Sketch** - kreativní kreslení
- Standardní kreslící software jako **Adobe Photoshop**, **Krita**, **GIMP** - fungují s tabletem jako vstupní zařízení

## Důležité poznámky

⚠️ **Vždy instalujte ovladače PŘED prvním připojením tabletu**
⚠️ **Pravidelně aktualizujte ovladače** - Huion vydává aktualizace s opravami
⚠️ **Huion Note je zdarma** - neplaťte za podezřelé verze z neoficiálních zdrojů

## Shrnutí instalace:

1. Stáhněte **Huion Driver** z huion.com
2. Nainstalujte ovladače a restartujte PC
3. Stáhněte **Huion Huion Note** z huion.com
4. Nainstalujte Huion Note
5. Připojte tablet USB kabelem
6. Spusťte Huion Note a užívejte si malování! 🎨

## Jak aplikace "Huion Note" vypadá a funguje

### Hlavní rozhraní aplikace:

Po spuštění aplikace Huion Note (mobilní nebo desktop verze) uvidíte:

**📱 Hlavní obrazovka:**
- **Knihovna poznámek** - seznam všech vašich kreseb a poznámek uspořádaných do složek
- **Náhledové obrázky** - miniaturní náhledy každé stránky
- **Tlačítko Connect** (Připojit) - v pravém horním rohu pro připojení tabletu

**🎨 Editační nástroje:**
- **Zvýrazňovač** (Highlighter) - pro zvýraznění textu
- **Guma** (Eraser) - mazání čar
- **Laso** (Lasso tool) - výběr a přesun objektů
- **Barevný výběr** (Color picker) - změna barvy pera
- **Vložení obrázku** - možnost vložit fotky do poznámek
- **Záznam hlasu** - nahrávání audio poznámek při psaní

**📤 Export funkce:**
- Export do **PDF** - pro sdílení dokumentů
- Export do **JPG** - pro obrázky
- Export do **Video** - přehrání celého procesu kreslení!
- Export do **Huion Note formátu** - pro zálohu

**🔄 Synchronizace:**
- Offline úložiště až **50 stránek** - můžete psát bez připojení
- Automatická synchronizace po připojení
- Cloud backup (pokud aktivujete)

### Připojení tabletu krok za krokem:

1. **Zapněte tablet** - objeví se zelená kontrolka (steady green light)
2. **Otevřete aplikaci** Huion Note na PC/mobilu
3. **Klikněte na tlačítko "Connect"** v pravém horním rohu
4. **Vyberte způsob připojení:**
   - "Connect via Bluetooth" → vyberte "Huion Note-X10" ze seznamu
   - Nebo **naskenujte QR kód** uvnitř obalu tabletu
5. **Hotovo!** - Tablet je připojený a vidíte své poznámky

## Důležité upřesnění o aplikaci

⚠️ **Pozor:** Aplikace pro Huion Note X10 se může jmenovat různě:
- **"Huion Note"** - hlavní aplikace (Android, iOS, možná Windows verze)
- **"Huion Note for PC"** - desktop verze (někdy vyžaduje emulátor jako BlueStacks)
- **Huion Driver** - ovladač pro rozpoznání tabletu jako kreslícího zařízení

Pokud nenajdete dedikovanou Windows verzi aplikace "Huion Note", můžete:
1. Použít **mobilní aplikaci** na telefonu/tabletu (nejsnadnější)
2. Použít **Android emulátor** (BlueStacks, MEmu) na Windows PC
3. Použít tablet jako **grafický tablet** v režimu "Pen Tablet Mode" s ovladači
