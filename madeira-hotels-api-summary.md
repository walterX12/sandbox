## 🏢 Detailní přehled poskytovatelů

### 1. 🔵 Booking.com API

**Základní informace:**
- **Inventář:** 29 milionů nabídek (hotely, motely, resorty, domy, byty)
- **Pokrytí:** 220+ zemí
- **Typ nabídek:**
  - Cca 400 000 tradičních ubytovacích zařízení
  - 2,3 milionu domů a bytů

**Výhody:**
- ✅ Největší výběr ubytování na světě
- ✅ Rozsáhlá databáze recenzí a hodnocení
- ✅ Silná značka známá uživatelům
- ✅ Spolehlivé real-time dostupnost

**Nevýhody:**
- ❌ Obtížný přístup k API (preferují větší firmy)
- ❌ Složitý proces schvalování
- ❌ Vysoké požadavky na objem rezervací

**Cena:**
- Není veřejně dostupná
- Obvykle komise z rezervací
- Kontaktujte přímo pro cenovou nabídku

**Kdy použít:**
- Pro střední až velké firmy s ustáleným businessem
- Když potřebujete největší výběr ubytování
- Pro projekty s vysokým objemem rezervací

---

### 2. 🔴 Expedia Rapid API

**Základní informace:**
- **Inventář:** 700 000+ ubytování
- **Pokrytí:** Globální
- **Geografie:** 400 000+ inteligentních geografických definic
- **Technologie:** RESTful API

**Výhody:**
- ✅ Konkurenční ceny
- ✅ Dynamický obsah properties
- ✅ Modulární architektura
- ✅ Lehký a rychlý RESTful API
- ✅ Součást Expedia Group (Hotels.com)

**Nevýhody:**
- ❌ Selektivní s partnerskými integracemi
- ❌ Preferuje větší firmy před startupy
- ❌ Proces od smlouvy k API připojení může trvat měsíce
- ❌ Vyžaduje značné inženýrské zdroje

**Cena:**
- Variabilní pro každého partnera
- Závisí na: trhu, pokrytí, objemu rezervací
- **Cenové modely:**
  - Provize za rezervaci (pay-per-booking)
  - Měsíční předplatné
  - Volume-based pricing
  - Možné setup/integrační poplatky

**Kdy použít:**
- Pro etablované firmy s technickými zdroji
- Když potřebujete prémiové služby a dynamický obsah
- Pro OTA s vysokými objemy

**Nevýhody:**

**Cena:**
- Není veřejně dostupná

**Kdy použít:**
- Pro enterprise projekty
- Když potřebujete pokročilé funkce a metadata

**Dokumentace:**
- 🔗 developers.amadeus.com

- ✅ Multi-currency podpora

- ✅ Code samples a best practices

- ✅ Skvělé pro OTA a agentury

**Nevýhody:**
- ❌ Menší inventář než Booking.com/Expedia

- Závislá na modulech (hotels, transfers, activities)

**Kdy použít:**
- Pro online travel agencies (OTA)

- 🔗 developer.hotelbeds.com

## 💰 Cenové modely

### Běžné cenové modely Hotel API (2026)

| Model | Popis | Vhodné pro |
|-------|-------|-----------|
| **Pay-per-booking** | Provize za každou rezervaci (5-20%) | Začínající projekty |
| **Monthly subscription** | Měsíční fixní poplatek | Střední objemy |
| **Volume-based** | Cena podle počtu rezervací | Velké objemy |
| **Setup fee** | Jednorázový integrační poplatek | Všechny typy |
| **Hybrid** | Kombinace výše uvedených | Enterprise |

### Typické náklady (odhad 2026)

- **Setup fee:** $0 - $5,000 USD
- **Monthly fee:** $0 - $500 USD/měsíc
- **Per-booking commission:** 5% - 20% z hodnoty rezervace
- **Enterprise contracts:** Individuální (často $10,000+ měsíčně)

## 🔧 Technické informace

### Technologie

| Poskytovatel | Protokol | Formáty | Rate limiting |
|-------------|----------|---------|---------------|
| Expedia | RESTful | JSON | Ano |
| Amadeus | RESTful | JSON | Ano |
| Hotelbeds | HTTPS | XML/JSON | Ano |
| Booking.com | RESTful | JSON | Ano |
| Avis Budget | RESTful | JSON | Ne (zatím) |

### Základní workflow pro rezervaci

```
1. Hotel Search (vyhledání)
   ↓
2. Hotel Details (detaily + ceny)
   ↓
3. Room Availability (dostupnost pokojů)
   ↓
4. Booking Request (rezervace)
   ↓
5. Booking Confirmation (potvrzení)
   ↓
6. [Optional] Cancellation/Modification
```

### Klíčové funkce k ověření

- ✅ Real-time availability
- ✅ Dynamic pricing
- ✅ Multi-currency support
- ✅ Cancellation policies
- ✅ Payment options (pre-paid/post-paid)
- ✅ Modification support
- ✅ Hotel metadata (photos, amenities, reviews)
- ✅ Geographic search
- ✅ Filter options (stars, price, amenities)

## 📚 Doporučení

### Pro startupy a malé projekty
1. **Priceline API** - jednodušší přístup
2. **Hotelbeds API** - kvalitní dokumentace
3. **RateHawk** - B2B wholesale

### Pro střední firmy a OTA
1. **Hotelbeds API** - optimální poměr cena/výkon
2. **Amadeus API** - pokročilé funkce
3. **Expedia API** - pokud máte technické zdroje

### Pro enterprise projekty
1. **Amadeus API** - nejkomplexnější řešení
2. **Booking.com API** - největší inventář
3. **Expedia API** - premium služby

### Doporučený přístup pro výběr API

```
1. Definujte požadavky
   - Cílový trh (B2B/B2C)
   - Očekávaný objem rezervací
   - Budget
   - Technické zdroje

2. Vyhodnoťte pokrytí
   - Počet hotelů v cílových destinacích
   - Kvalita nabídek
   - Ceny

3. Testujte sandbox
   - Kvalita API dokumentace
   - Rychlost odpovědí
   - Dostupnost podpory

4. Vyjednávejte podmínky
   - Získejte nabídky od několika poskytovatelů
   - Porovnejte cenové modely
   - Ověřte SLA (Service Level Agreement)
```

## ⚠️ Důležité poznámky

### Přístup k API
- **Booking.com a Expedia** jsou **velmi selektivní** s partnery
- Preferují firmy s **ustáleným businessem** a **vysokými objemy**
- **Startupy** by měly začít s **Priceline, Hotelbeds nebo RateHawk**
- **Proces schvalování** může trvat **týdny až měsíce**

### Technické požadavky
- Většina API vyžaduje **HTTPS** připojení
- Nutná implementace **error handlingu**
- Doporučeno použít **caching** pro optimalizaci
- Ověřte **rate limits** před produkcí

### Compliance a právní záležitosti
- Ověřte podmínky použití (Terms of Service)
- Kontrolujte licenční omezení pro zobrazování obsahu
- GDPR compliance pro evropské zákazníky
- PCI DSS pro zpracování plateb
